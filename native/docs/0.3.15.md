# VectorDash 0.3.15 preview

- Quick Look stays hidden until its image and first frame are ready, then opens centered over search at the displayed image size with path, score and match reason below.
- Ctrl+F returns to the search input and selects the whole query.
- Clipboard word matching handles multiple words in any order. Literal text matches come before image-meaning results. Rows are left aligned with full date/time; image thumbnails appear on the left. Thumbnail caching is bounded and released in tray mode.
- Optional Text to speech settings in AI: base URL, protected API key, model and voice. Refresh reads models and tries server voice lists; manual IDs remain available when discovery is unsupported. Uses the [OpenAI-compatible speech endpoint](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create). Read aloud sends answer text to this configured server and plays generated audio locally. Long answers are split into bounded requests; Stop interrupts downloads/playback and temporary audio is removed.
- AI buttons are ordered Screenshot, New Conversation and Send, with a smaller Read Aloud toggle under Send. Follow-up questions return to the newest response after scrolling up.
- Replies have larger bold You/AI labels, clickable/copyable sent screenshot thumbnails, last-response Copy and speaker controls, and prompt/decode rates when reported by the server.

Validation: 108 automated tests passed. Native main/popup fixtures checked clipboard layout/word matching, select-all search, screenshot rendering and AI controls. A silent local TTS fixture verified automatic playback and bearer authentication, with no real microphone or user data. A native Quick Look visibility test found stable image-sized geometry from first appearance. A follow-up after scrolling up returned to the bottom of the conversation. Setup and portable packages were built with checksum verification.

TTS voice discovery is a server extension: Refresh tries GET audio/voices then GET voices; unavailable lists leave a manual Voice ID field. Timing rates are shown only if returned by the server, not inferred from local elapsed time. The optional TTS service does not load a local TTS model in VectorDash.
