# VectorDash 0.3.25 Beta 5

- Added core interface localization for English, Spanish, Brazilian Portuguese, French, German, Italian, Russian, Simplified and Traditional Chinese, Japanese, Korean, Hindi and Vietnamese. Select a language in Settings; system language is the default. Advanced settings, detailed errors and some dialogs remain English in this first phase.
- Fixed screenshot attachment and other dialogs being clipped by a collapsed quick-search window. The popup expands for dialogs and returns to its normal compact height afterward.
- Successful manual scans now satisfy older recovery work without discarding newer file notifications. Known file-change notifications stay targeted and are processed in bounded batches; unrelated deferred indexing jobs are no longer resumed by a targeted update.
- Coalesced index statistics refreshes to avoid repeated database counts during notification bursts.
- Opening a selected application or file no longer waits for an embedding request. Launch failures are reported in search.
- Includes Beta 4's mapped network drive indexing fix and all earlier Beta 3 improvements. Windows 10 support remains beta.

Automatic monitoring still follows idle and gaming rules. Manual Update index and configured scheduled scans intentionally check the configured sources; startup recovery or lost notifications can also require a catch-up scan.

Validation: 178 automated tests passed (10 opt-in tests not run), all 13 language rendering checks passed, compact screenshot and sent-image dialogs retained visible action buttons, and four packaging regression tests passed.
