# VectorDash 0.3.44-beta.1

- Feature: Optional native Computer control and isolated Browser control let a tool-capable local or remote AI model interact with your PC; both are BETA and disabled by default.
- Feature: Computer control can discover and launch approved installed apps under your normal Windows account.
- Feature: Each control action supports Allow once, Allow all this session, or Don’t allow; New Conversation and Stop revoke permissions.
- Fix: Follow-up control requests retain recent verified tool results and require an actual computer/browser tool invocation before an answer is accepted.
- Fix: Tool-free success claims are blocked instead of displaying invented screenshots or actions.
- Fix: Previous-request snapshot IDs are rejected before clicking or typing, requiring a fresh observation on follow-up requests.
- Fix: Native control uses fresh observations, stable automation identities and explicit toggle states, with checks for stale or moved targets.
- Feature: Longer control tasks default to 48 actions per response, configurable up to 128; existing saved limits remain unchanged.
- Feature: Search settings can optionally copy original-resolution screen-area captures to the clipboard from either the screenshot button or its shortcut.
- Fix: Area capture restores the original AI window with the image attached, and image files can be dropped into Search, Clipboard or AI chat.
- Fix: AI tool selection toggles align to the far right in the full window and quick popup.

Computer/browser control remains BETA. Model planning and application accessibility vary; successful individual actions do not guarantee a whole task will complete. Test control in disposable windows first. Approved normal apps remain open when AI tools stop. Clipboard copying is opt-in.
