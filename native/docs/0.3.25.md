# VectorDash 0.3.25

- Camera RAW (BETA — additional camera testing needed) - Optional LibRaw support indexes and previews ARW, CR2/CR3, DNG, RAF, NEF, ORF, RW2, PEF, SRW and other supported camera formats using embedded previews first, with a separate development fallback and original files kept unchanged.
- RAW resource limits - Camera decoding runs in an isolated helper with input-size, memory, time and output-size limits, stays off by default and applies only to Full sources.
- Interface localization (BETA — native-speaker and complex-script testing needed) - Choose English, Spanish, Brazilian Portuguese, French, German, Italian, Russian, Simplified Chinese, Traditional Chinese, Japanese, Korean, Hindi or Vietnamese for application menus, settings, help, dialogs and tray controls.
- Windows 10 compatibility (BETA — actual Windows 10 device testing needed) - Windows 10 x64 version 2004/build 19041 or newer can install VectorDash with fallback visual effects, while Windows 11 remains the primary tested platform.
- Live source filtering - Removed sources, exclusions and nested Quick/Full rules immediately apply to search and MCP before bounded background cleanup removes stale entries.
- Progressive Hybrid search - Filename and exact-word results appear before semantic inference completes, and remain available if the embedding server fails.
- Immediate result actions - Opening an application or file no longer waits for an outstanding embedding request.
- Visual image ranking - Photo and image queries no longer gain misleading exact OCR keyword hits or bonuses, while explicit screenshot and text queries retain text matching.
- Consistent query words - Singular and plural image, photo and picture prefixes are handled consistently by keyword tokenization.
- Remote embedding warm-up - An opt-in Remote setting sends a small embedding request when Hybrid or Semantic search opens so an unloaded server can begin loading before typing.
- Chat model dropdown - A smaller model-name-only selector lists discovered LLM models, remembers discovery per server URL and applies the chosen model to subsequent conversation turns.
- Targeted change indexing - Known file and folder notifications process their affected paths instead of restarting unrelated source scans or deferred jobs.
- Durable change queues - Pending paths survive interruptions, event bursts are bounded and retained, and only genuinely lost notification coverage requests recovery.
- Recovery scan coordination - Successful manual scans satisfy older queued recovery work while preserving later notifications and explicit cancellation.
- Network share resilience - Inaccessible network subfolders no longer prevent accessible sibling files from indexing, and offline content records are retained.
- NTFS and notification fallback (BETA — broader drive and network testing needed) - Journal replay and folder notifications preserve targeted updates, while startup gaps or lost coverage can still require a catch-up scan under idle rules.
- Coalesced statistics - File-change bursts share bounded statistics refreshes instead of launching repeated full database counts.
- Bounded embedding batches - Small documents and images share limited batches, media batches fall back to single requests when required and interactive search gets priority between indexing batches.
- Prepare one batch ahead - Extraction overlaps the current embedding batch without building an unbounded queue.
- Fair long-file indexing - Long documents yield between saved chunk groups so smaller files can progress before all large-file work finishes.
- Resumable indexing - Completed chunks remain staged through interruptions and replace old searchable content only after the file finishes successfully.
- Quick or Full first - Sources can prioritize filename indexing or Full content work and continue durable deferred jobs without another drive crawl.
- PDF streaming - PDF processing releases pages between steps, reuses page renders for OCR and visual embeddings and checks cancellation between pages.
- Similar-frame skipping (BETA — scene-recall testing needed) - Optional near-identical frame suppression reduces repeated video embeddings while retaining scene changes and timestamps.
- Learned indexing estimates (BETA — approximate timing) - Backend-specific processing history estimates known queued Full work after enough completed samples.
- FP16 semantic cache (BETA — collection-level accuracy testing needed) - Optional FP16 vector storage reduces cache RAM while scoring and the on-disk index remain FP32 without reindexing.
- Rank Calibration (BETA — broader relevance testing needed) - Optional search-time channel adjustment compares text, images and audio without changing model embeddings or requiring an index update.
- Resizable previews - Search and Clipboard dividers remember their widths and fit images or videos to the available space without distorting aspect ratio.
- Picture grid - Images and Videos can use a keyboard-accessible thumbnail grid with its own remembered preview width.
- Video thumbnails (BETA — codec and device testing needed) - Visible videos load single-frame thumbnails through a bounded background queue and RAM cache with no persistent thumbnail files.
- Compact popup dialogs - Filter, screenshot attachment, saved-search and confirmation dialogs expand or scroll within quick search and restore the compact window afterward.
- Full preview space - Search results and media previews use the available height instead of reserving empty space at the bottom.
- File-type dropdown - The search-bar type label opens the full list of file categories.
- Unified status footer - Centered search, model, dictation and AI notices expire after completion, show response timing and leave room for Open full app and shortcuts.
- Model loading outline - A circulating blue outline indicates embedding model loading or response waits.
- Read-aloud controls - The footer provides themed pause/resume and stop icons, with pause affecting already buffered audio playback.
- Tray Exit - Exit requests are queued reliably, wake the app after enqueue and are processed before close-to-tray interception.
- Update channels - Release accepts full releases only, Beta includes pre-releases and version ordering prevents stale update offers.
- Update relaunch - Installing an update through the app explicitly reopens VectorDash after silent setup completes.
- Update changelog - About shows changes across releases since the installed version before updating.
- Embedding validation - Zero, non-finite, inconsistent and incorrectly mapped vectors are rejected rather than silently corrupting the index.
- Parser hardening - Additional sensitive filenames are excluded before reading, parser workers do not inherit unrelated server credentials and production uses the bundled PDF renderer.
- Release verification - Official releases require a successful build of current main, clean portable packages and verified download and upload checksums.

Validation: 193 automated tests passed, with 10 opt-in tests not run in that local suite; the release workflow additionally checks bundled PDF and native video behavior.

Ten checksum-verified CC0 RAW samples from ten formats decoded and indexed using an actual EmbeddingGemma server in an isolated index, producing ten vectors in 4.9 seconds with the optimized build and a warm server; an unchanged rescan used zero embedding requests, nine files used embedded previews and one DNG required development fallback.

These small-sample timings are observations, not general throughput or relevance guarantees; the BETA features above need additional testing on real cameras, Windows 10 devices, codecs, languages and mixed-media collections.
