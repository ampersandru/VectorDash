# VectorDash 0.3.6

- Automatic file-change indexing obeys idle conditions even with periodic scanning set to Manual. Scheduling now explains the difference.
- Optional NTFS journal replay reads bounded buffers and commits a cursor only after a successful update. Valid saved cursors can replace startup recovery scanning when every source is covered. Expired/replaced journals, unresolved parents, unsupported drives and denied volume access fall back to folder notifications and recovery. No journal is created or reset; no automatic elevation occurs. Fast initial MFT enumeration is not implemented in this phase.
- Search modes are Both, File/Folder Names and Semantic. Sources is a multi-selection menu with All sources first; inference reuses one short-lived query vector across selected sources.
- Filename wildcards/name filters, extension lists, size comparisons and local modified-date filters. Examples: `dog*.jpg size:>1MB`, `report ext:pdf modified:>=2026-10-01`, `ext:pdf modified:today`. Metadata filters are applied before semantic candidate limits.
- Save searches including query, mode, types, source selection and exclusions; rename/remove them in Settings.
- Ctrl+F and Back to search return from settings. Tab/Shift+Tab cycle types, highlight the selector and retain input focus.
- Dark slider tint/track improvements; popup material no longer extends an extra rectangular frame outside its clipped client region. DigUp text removed from About; license/README acknowledgements retained.
- Audio-only playback disables video/album-art display. Playback errors, including a player exiting successfully while reporting an error, become visible in app logs. Starting playback replaces the previous player, Stop/Exit terminate it, and status reports playback progress/completion.

Validation: 65 regression tests passed, including filename/size/date predicates before result limits, metadata-filtered semantic search in Balanced/Low memory, multi-source unions, saved-search serialization, USN record validation and successful-batch-only checkpoint commits, plus automatic indexing with Manual scheduling and idle gates. Live volume access and media/UI checks are recorded separately.

Live checks: standard-user access to C: journal was denied and G: exFAT returned unsupported; fallback remained available. Full live privileged journal replay remains unverified in this environment. Production WAV/MP3 tests seeked to one second, completed playback and reported no errors; a missing-file control correctly returned a visible diagnostic. Actual Windows input confirmed Tab changed the file type, highlighted it, and subsequent typing stayed in the search field. Light popup clipping and source-menu layout were inspected.
