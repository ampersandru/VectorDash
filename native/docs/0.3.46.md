# VectorDash 0.3.46

## Search and indexing

- Video frames can use optional OCR with the configured languages. Results retain frame timestamps and distinguish visual, on-screen text and audio evidence. Corrected FFmpeg sampling timestamps.
- Added bounded multi-part reranking for combined visual/audio and ordered video queries, punctuation-normalized identifiers, and readable RTF text extraction. Semantic matches remain candidates, not guaranteed scene understanding.
- Improved NTFS journal targeting: ambiguous directory names no longer trigger recursive walks, unchanged candidates are skipped, and exclusion changes preserve valid journal coverage.
- Interrupted monitoring work resumes affected paths. Full scans retire older covered recovery requests before catch-up scheduling. Quiet journal progress is checkpointed, and automatic-run history records stop/failure reasons.

## Network drives and automatic updates

- Added configurable periodic network catch-up (default enabled, five minutes between completed passes). SMB notifications remain active when periodic catch-up is off; startup, reconnect and genuine coverage-gap recovery can still run.
- Network safety checks use bounded background metadata batches and durably queue only differences. Improved notification buffering and bounded branch watches reduce broad recovery work.
- Follow-up updates receive a fresh batching window rather than immediately starting another job with an expired timer. Network directory creation/rename discovery uses incremental reconciliation.
- Unavailable child watches are skipped when a healthy parent can detect their return. Branch failures restart only the closest affected watch. Share-level reconnect retries remain active, and inaccessible listings retain indexed records.

Safety reconciliation still enumerates metadata over a complete pass; it spreads that work out rather than eliminating it. Explicit full updates and genuine local subtree changes can still require broader discovery.

## Windows minimize compatibility

- Added **Use native Windows minimize (compatibility mode)** in Settings → Startup and window behavior, **off by default**, for Windows 10/11 systems where the regular taskbar minimize method fails.
- Applies to the minimize button and Close configured to minimize to taskbar. Tray behavior is unchanged. Native minimize requests are logged for troubleshooting; confirmation on the reporter's affected system is still pending.

## Updating

No whole-index rebuild is required. To refresh video OCR and RTF contents, enable the desired OCR engine/language packs and update the relevant Full-indexed folders. Video OCR adds processing time and follows existing sampling settings.

Includes a reproducible synthetic retrieval benchmark and monitoring regression tests. The latest beta passed 472 Rust tests and 10 Python tests; controlled T: tests verified exact-file reconciliation and nested/new-branch notifications. These are correctness checks, not general NAS performance or model-accuracy claims.
