# VectorDash 0.3.44

## New features

- **Computer and browser use (beta):** optional AI tools can operate Windows apps and an isolated browser, with Allow once / Allow this session / Don’t allow approvals. Includes installed-app discovery, normal Windows app launches and browser password entry with hidden values in observations and debug exports.
- **Optional Qev decision model:** local or remote, with Off, Suggest and Execute modes, optional vision, managed downloads and request-scoped loading/unloading.
- **Local speech:** Paradee v2f lite/v2f/v2g and Kokoro 82M FP16/Q8. Paradee now offers ten voices: Heart, Wren, Everly, Hadley, Bryony, Maeve, Miles, Trevor, Edwin and Hugh. New voices download individually. Kokoro supports CPU or DirectML GPU; Paradee uses CPU SIMD.
- **Read-aloud streaming and lifecycle controls:** start ordinary-chat speech from completed sentences, select streaming or buffered playback, and unload immediately or after an idle timeout. Remote connection settings survive switching to local providers.
- **Settings search:** search from every settings panel, with matches from the current panel first, followed by other matching panels. Click a result to open its section.
- **Speech management:** model storage, RAM and dedicated VRAM reporting in Status, reordered component rows, consistent remote readiness, and local speech uninstall controls.
- **Control debugging:** opt-in combined prompt/response/step exports with per-step token, prompt-cache, action and Qev diagnostics.
- **Image input:** drag images into Search, Clipboard or AI Chat; optionally copy area captures to the clipboard.

## Fixes since 0.3.42

- Restore the previously used full or popup AI window after selecting a screenshot area, with the capture attached.
- Keep long AI responses and tables within the window, improve source-link rendering and underline links.
- Read clickable link labels naturally without speaking hidden destinations or splitting words and punctuation around inline formatting.
- Preserve the latest follow-up request, research evidence and stable prompt prefixes during control-history compaction.
- Improve native app discovery, launch verification, dialog targeting, mixed-DPI captures, keyboard input, text replacement and post-action observations.
- Guard file/list rows against accidental typing or renaming, and prevent clipboard shortcuts from operating on an unfinished inline filename editor.
- Improve deep control pagination and content-pane scrolling; stop repeated unchanged actions and reject unsupported success claims.
- Improve Qev routing and diagnostics, and avoid redundant vision capture for uniquely grounded targets.
- Fall back correctly when remote speech servers reject streaming formats. Stop owned local model workers when VectorDash exits.

## Notes

Computer/browser control and Qev remain beta features. Qev assists with target selection; it does not replace the main model, and current measurements do not demonstrate an overall speedup. Windows foreground restrictions can still affect automation. Password entry uses existing browser approvals; credentials included in chat are sent to the selected chat provider.
