# VectorDash 0.3.5

First official native Rust release. Setup and portable builds contain no Python runtime.

- Automatic changed-file indexing is the first Scheduling option. Saved settings start/stop recursive monitoring; status shows pending changes and idle blockers.
- Child changes no longer trigger parent-folder metadata rescans. New and renamed folders still scan their subtree. Startup/notification-overflow recovery and scheduled scans check all sources, reusing unchanged content.
- Automatic-run history identifies targeted versus recovery/scheduled updates and separates new filename entries from metadata/mode changes. Logs now has a persistent, bounded File log tab.
- Source paths are left aligned in a slimmer pane. Exclusions shrink to their contents up to a height limit.
- A bottom red Save / outlined Undo bar replaces individual settings Save buttons. Appearance previews remain temporary until saved.
- About sits above Exit and includes version, license, project links, update settings and a changelog covering newer releases.
- Native clipping applies the rounded region to both the window and its compositor blur surface, including after resizing/material changes.

Validation: 54 native regression tests, including actual Windows recursive notifications, new/modified Quick and Full sources, idle blocking, parent-folder events, encrypted/plain databases and changelog selection. Live user logs confirm newly added text/PDF files indexed in 0.34–0.49 seconds and the server automatically unloaded after five idle minutes. Production-EXE testing also verified automatic new/modified Full content through the real extraction subprocess, model-free Quick indexing and file-log output. Light/dark window captures, Sources alignment, About/update controls, Undo behavior and portable-package contents were checked.

Limitations: changes while the app is closed require recovery scanning; persistent NTFS USN replay is not implemented. Network monitoring depends on the filesystem/redirector and access permissions. A notification flood can require a recovery scan. Standard Windows dialogs are supported; custom/elevated dialogs may differ. The installer remains unsigned.
