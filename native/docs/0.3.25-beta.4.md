# VectorDash 0.3.25 Beta 4 — Network share indexing fix

- Fixed a network subfolder enumeration or metadata error stopping the entire source scan. Accessible sibling folders and files now continue indexing. This applies to counting and both Quick and Full scans.
- A whole-source early stop now requires a network error plus a failed root-directory enumeration probe. Existing records are retained when a source or subtree is inaccessible.
- This addresses a reproduced mapped SMB drive failure where one subfolder returned Windows network error 59. No source exclusions or index rebuild are required; run **Update index** after installing to discover previously missed files.

Includes all Beta 3 search/playback fixes. Windows 10 support remains beta. Localization is being developed separately in PR #17 and is not included in this build.

Validation: 163 automated tests passed (10 existing opt-in tests not run), four packaging regressions passed, and the packaged executable was tested against the actual failing SMB subtree in isolated profiles. Beta 3 indexed 0 files and missed the sibling-file search; Beta 4 counted/indexed 1,255 files in 0.74 seconds, skipped four inaccessible paths and found the expected sibling file. This is a targeted regression check, not a general network throughput benchmark.
