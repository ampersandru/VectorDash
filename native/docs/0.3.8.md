## Enable an NTFS journal
In an Administrator terminal, first run fsutil usn queryjournal H:. If the journal is inactive, run fsutil usn createjournal m=67108864 a=8388608 H: and query again. This example uses a 64 MiB target with an 8 MiB allocation delta; Windows may temporarily exceed those sizes. Use a drive letter, not a folder path. Do not recreate an existing active journal unnecessarily.

Enable automatic changes and NTFS journal tracking in Scheduling, save, and restart VectorDash so volume availability is reprobed. Read access to the volume is also required: creating a journal does not solve Access denied. This preview has no privileged journal service. Folder notifications remain the fallback and automatic updates continue to obey idle conditions. exFAT does not support USN journals.

Reference: https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/fsutil-usn
