# VectorDash 0.3.16 preview

- Regular search’s right-side mode/filter/saved-search controls stay on the same line as Search, Clipboard and AI, including with the sidebar collapsed.
- TTS voice discovery sends the selected model ID, supporting audio.cpp servers hosting several models. Changing a model refreshes its voices automatically, with debouncing for typed IDs and stale-response checks. Voice discovery notices stay in TTS settings and clear when appropriate; they no longer appear in the search footer. See the [audio.cpp voice-list API](https://github.com/0xShug0/audio.cpp/blob/main/app/server/README.md#get-v1audiovoicesmodelid).
- AI’s response dropdown sits immediately right of Screenshot. Brief asks for 3–4 focused sentences; Medium asks for 4–6; Full sends no length instruction or max_tokens override, allowing the server’s defaults. Instruction cost is included in the context budget, and changing length does not leave stale instructions in conversation history.

Validation: 112 automated tests passed. Native main/popup fixtures verified aligned toolbar positions, the response dropdown, actual request payloads for all three lengths, and separate voice lists for two models on an audio.cpp-compatible local fixture server. Setup and portable packages were built and checked.
