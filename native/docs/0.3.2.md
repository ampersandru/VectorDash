# Native preview 0.3.2

- Index updates accept legacy unknown-size (-1) records; failed updates now record the actual error in the application log.
- Quick search has a search-first layout, **Search Anything** prompt, bottom-left Open full app, unclipped filters, animated expansion/collapse, and dismissal when focus leaves it. Quick Look remains in front of its parent and returns focus when closed.
- Native Windows blur-behind now extends across the transparent popup rather than adding Acrylic's own opaque tint. Appearance transparency and gradient remain adjustable. Windows controls the blur radius; system transparency settings can affect the effect.
- Purple tray icon, icon-only collapsed Exit, highlighted dropdown states, arrow-key hints, and Escape follows the main window's configured close behavior.
- Models & hardware includes configurable idle unloading (enabled by default, five minutes). Active indexing is protected from unloading. Remote runtimes are controlled by their host; OCR/media extraction helpers run only when needed.
- Automatic idle indexing checks CPU/GPU and optional user inactivity between files **and embedding batches**, pausing until eligible. A request already in progress finishes first. Manual indexing follows Pause/Cancel instead. Disabled keyboard/mouse inactivity does not gate indexing and its counter is hidden.

## Explorer and file dialogs

Enable Explorer/dialog integration in Settings, open Explorer or a standard Windows Open/Save dialog, and press Ctrl twice. Search for a file and press Enter. In standard dialogs the selected path fills the filename field; you still confirm Open/Save. For custom or elevated dialogs, use Copy path.

This is activation and path transfer, rather than a search pane embedded into Explorer or support for every third-party dialog. Full Listary-style shell embedding remains unimplemented.

No database conversion or model reinstall is required. Exit VectorDash from its tray/menu before installing; closing a window may only hide it. The installer is unsigned and this remains a native preview.
