# VectorDash 0.3.14 prerelease

- Full-width microphone waveform inside the search input, in the main window and popup. Recording instructions are hidden; useful transcription errors remain visible.
- Transcription removes sentence-ending punctuation while preserving punctuation inside your query. AI dictation still submits automatically.
- Recording trail is 50% longer, with red fading into orange over its last half. AI processing uses the same trail size with a purple-to-blue gradient.
- New Enable AI chat setting. AI stays hidden when disabled or no model is selected; Clipboard stays hidden when history is disabled. Tab and Shift+Tab skip hidden modes. MCP remains independent.
- Popup footer shows search feedback instead of background indexing summaries.

Validation: 101 automated tests passed, plus native main/popup checks for waveform rendering, both trails, punctuation cleanup, AI auto-submit, hidden modes and popup status filtering. AI tests used a local fixture server.

Windows 11 x64. Setup and portable downloads include SHA-256 checksums. Setup is unsigned and may trigger a Windows warning. This is a prerelease; v0.3.12 remains the latest stable release.
