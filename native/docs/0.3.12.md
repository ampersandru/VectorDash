# 0.3.12 test build

- Search/Emoji/Clipboard/AI toolbar with themed MDI icons. Filter panel supports file types, multiple sources and wildcard exclusions. Mode, Filter and Saved searches align left; Save Search appears beside the query and opens a naming popup.
- Offline emoji grid with Unicode/CLDR keyword search.
- Optional text/link/image clipboard history with timestamps, selected-item previews, expiry and application exclusions. Windows-account-protected payloads; up to 500 entries / 128 MiB, text 16 KiB and images 4 MiB / 16 MP. Only one image preview is loaded.
- AI settings above Logs: OpenAI-compatible /v1 URL, protected key, model refresh/dropdown, context budget and shortcut. MCP settings moved here.
- Tab switches AI/Search; Enter or right-aligned Ask sends. Markdown replies, follow-ups, Ctrl+C reply copy, Stop, wheel scroll and Up/Down paging. Purple-blue animated request outline; popup remains open while answering.
- Screenshot chooser for monitor, open window or cropped area. Review and attach first; only Ask/Enter sends it. Requires a vision model.
- Optional local English Parakeet TDT 0.6B v2 dictation: red circular microphone or configurable Ctrl+Shift+D search shortcut. Click again to transcribe; Escape cancels. Native sherpa-onnx on CPU or NVIDIA CUDA, verified downloads, on-demand load and immediate unload. CPU ~500 MB download; CUDA model/runtime/libraries ~3 GB.
- Clipboard and screenshots never enter the file index or MCP. AI receives conversation text and only explicitly attached screenshots. File-copy formats are not captured. Conversations are bounded and kept for the app lifetime.

Max context is an estimated client budget; the server controls its actual context/tokenizer. Speech downloads are optional and absent from the base installer.

## Verification

83 regression tests passed, including image-history protection/expiry, screenshot crop bounds, multimodal request encoding, stop-before-response cancellation and existing indexing/security checks. Real publisher audio transcribed successfully with both CPU and CUDA runtimes; each inference process exited after completion. Cold child startup plus transcription measured ~1.85 s CPU and ~18.22 s CUDA on this PC. This is one short fixture, not a throughput benchmark; loading the CUDA model can dominate short dictation.

Interactive verification confirmed the Filter type/source dropdowns open and exclusions remain editable. Further desktop UI testing was stopped by the user, so real microphone recording, system clipboard image round-trip and screenshot capture/presentation still need user acceptance testing. Backend image/history/crop/vision-wire tests used synthetic data.
