## Testing automatic changes and the NTFS journal
Enable Automatically index changed files and folders in Scheduling and save. Optionally enable NTFS journal tracking. Watch Schedule status: it reports the number of accessible journals, queued work, and any idle condition blocking updates. Create a uniquely named file in an included source, wait for the 10-second debounce and configured idle conditions, then search its exact filename. Modify it and check File logs for the targeted update.

Journal tracking requires NTFS, an existing active USN journal, and permission to read the volume journal. The app does not create journals or request elevation. If unavailable, recursive Windows folder notifications remain active, including on exFAT. Startup catch-up and notification overflow recovery scans cover missed changes; periodic scans follow the selected schedule. All automatic change updates still obey idle conditions in Manual mode. Both Quick and Full sources are monitored; unsupported Full-source content is still indexed by filename.

A zero journal count means the fallback is active, not that journal replay has been verified. This build's real Windows test covers notification fallback with the journal option enabled; privileged journal replay still needs testing on an accessible active journal.
