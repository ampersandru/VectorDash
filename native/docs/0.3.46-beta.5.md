# VectorDash 0.3.46-beta.5

Adds an optional native Windows minimize compatibility mode for Windows 10/11, disabled by default for both new and existing installations.

Enable **Use native Windows minimize (compatibility mode)** in Settings → Startup and window behavior, then Save. With Minimize behavior set to Taskbar, try the title-bar minimize button in restored and maximized windows. Restore from the taskbar and repeat. The option also applies when Close is configured to minimize to the taskbar; Tray behavior is unchanged.

The alternative queues Windows' standard minimize system command instead of the UI framework viewport command. If the command cannot be queued, the existing method remains the fallback. Logs record native minimize requests to help diagnose issue #25. A queued request is not proof that Windows kept the window minimized; reporter testing is still needed.

Validation: 472 Rust tests and 10 Python tests passed, including old-settings/default-off and enabled-setting persistence coverage. Reporter confirmation is needed for the affected Windows installation.
