# VectorDash 0.3.10
- Cancel stops the current scan and holds queued automatic/recovery work for the current session. Use Update index or Scheduling -> Resume automatic indexing to continue.
- Editing roots, indexing modes or exclusions stops an in-flight scan at the next safe checkpoint. Save restarts with the latest sources; Undo restarts with the saved sources.
- Removing a drive after explicit Cancel does not restart the cancelled scan.
- Source restarts retain automatic/idle gating for an originally automatic scan.
- Settings must save successfully before a restart is queued. Completed files are retained.

Compatibility: the installer remains Windows 11-only (minimum build 22000). Windows 10 compatibility and Linux desktop/server releases are planned; neither is claimed by this patch.

Validation: 68 regression tests passed, including cancel/resume of pending recovery, updated-root restart, and removing a source after explicit cancellation. Installer/portable packages and checksums were verified.
