# VectorDash 0.3.25 Beta 3 — Search and playback fixes

- Read-aloud pause now pauses the active audio player, including already buffered audio, and resumes it when requested. Pause/resume and stop use themed icons with tooltips.
- Footer status centers in the space between Open full app and keyboard shortcuts.
- Picture grids remember their own preview-divider width independently of regular search and Clipboard.
- Visible video results load a single-frame thumbnail using a bounded background queue. Thumbnail textures are limited to 96 entries at at most 128 pixels per side (up to about 6 MiB decoded texture pixels); no thumbnail files or index blobs are stored. Temporary codec memory is additional, with at most two jobs active. Unsupported files fall back to their file icon.
- The file type label inside the search bar is now a dropdown listing all types.
- Opening Filter expands a compact popup; the panel is constrained and scrollable. Closing it restores the compact height.

Windows 10 support remains beta; actual Windows 10 device validation is still needed. See the beta 2 notes for indexing/cache options and their test limits.
