# VectorDash 0.3.25 Beta 1 — Search and indexing stability

This is a pre-release for testing. Beta installers use a separate asset name so older updaters cannot accidentally offer them as full releases. Install this beta manually once to access the channel selector.

- About → Updates now has Release and Beta channels. Release is the default and offers only full releases; Beta also offers pre-releases. Save the selection to apply it. Beta versions use semantic version ordering, and switching channels discards stale update checks/download offers.

- Search and Clipboard preview panes have draggable dividers with remembered widths. Images fit the available space without changing aspect ratio; double-click the divider to reset.
- Removed sources and exclusions take effect immediately in search and MCP, including when no sources remain. Old index entries are cleaned in small background batches under idle rules.
- Hybrid search shows file names and matching document words before semantic inference finishes. Model outages preserve those results; superseded queries disconnect promptly.
- Small documents and images share bounded embedding batches. Interactive semantic searches get priority between indexing batches.
- PDF indexing reads and releases one page at a time, checks cancellation between pages, and reuses rendered pages for OCR and visual embeddings.
- Interrupted indexing retains completed embedding chunks and pending change paths in the index database. Recovery re-extracts the file but reuses staged vectors. Current-source rules still apply.
- Automatic change retries retain their targeted scope, back off during outages, and preserve explicit cancellation across restarts.
- Embedding responses reject zero, non-finite, inconsistent, or incorrectly mapped vectors. Unsupported media batches fall back to single requests.
- Additional secret filenames and private-key formats are excluded before file reads. Parser processes receive no unrelated server credentials.
- Release builds use the bundled PDF renderer unless explicitly started with `--allow-development-overrides`. Official publication can verify a successful build of current main and package checksums.

Performance measurements and test conditions are in [BENCHMARKS.md](BENCHMARKS.md). Unsigned Windows builds may still prompt SmartScreen.
