# Native preview 0.3.1

Restores the familiar purple interface and fixes the first Rust preview's reported regressions.

- Saved Dark/Light/System appearance applies at startup. Popup transparency, independent color tone and gradient use one rounded alpha surface with the Windows backdrop. Native Windows fonts, MDI sidebar icons, purple scrollbars and rounded controls are restored.
- Main and popup title areas can be dragged. Closing to tray keeps quick search available; the shortcut wakes the hidden window and focuses its search input. Background scheduling and indexing no longer depend on drawing the window. Progress messages cannot block a hidden UI queue.
- Compact left-aligned results have thumbnails or Windows/file-type icons. Applications and Windows settings have bold **App** / **Settings** labels. Quick Look opens in a separate 1040 × 800 window; Space/Escape closes it and returns to search.
- Setup choices persist. OCR has a separate enable switch and a clear ready/disabled status. Existing Tesseract installations are detected and reused; reinstalling all models is unnecessary. CUDA/Vulkan setup and device selection share one backend decision, with automatic device enumeration and backend compatibility checks.
- The low-integrity OCR worker now sends PNG rather than JPEG to Tesseract. This avoids a Windows Leptonica temporary-file failure without granting the worker additional write access. OCR failures are logged. Refresh the Full index once to repair affected photos/scanned PDFs from the first native preview; Quick-name entries are reused.
- Scheduling includes CPU/GPU usage thresholds, keyboard/mouse inactivity, AC power, selected days/time, minimum idle interval, maximum run duration and history. Irrelevant fields disappear. Windows usage counters are sampled in a background thread; idle gates apply between files instead of delaying every embedding request.
- Sources restores image/audio/video switches, PDF page-image embeddings, visual detail and frame sampling. Window close/minimize behavior, startup, theme controls, exclusions, performance profiles, encryption and MCP remain configurable. Models remain lazy.

Validation: 27 native tests, including first-frame theme, saved setup/OCR preferences, backend selection, non-blocking notifications and scheduling without a visible UI. GUI smoke fixtures cover main/popup dark/light modes, empty popup, Sources/Models/Scheduling/Logs, hidden-window restore and the separate preview. Installed Tesseract reads an invoice fixture inside the restricted worker. Native Windows program-icon extraction is checked.

The setup remains unsigned. Exit the running VectorDash preview before updating. The native preview uses the same VectorDash-Rust data folder; no database conversion or model re-download is needed for this update. Full legacy feature parity and compatibility with every custom file dialog remain under review in PR #4.
