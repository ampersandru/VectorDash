## New features in 0.3.41

- Feature: Web search adds optional SearXNG, Degoog and Brave providers, Enter-to-search, provider selection and opening results in your default browser.
- Feature: Optional Web previews show small provider-supplied thumbnails without running a browser or keeping a persistent image cache.
- Feature: AI Web access lets compatible models search for current information and cite sources, with a separate provider selector, configurable concurrency and bounded searches that finish with an answer or an explicit source fallback.
- Feature: Dedicated Clipboard settings add independent text/image capture, retention and storage limits, app exclusions, pause capture and skip-next-copy controls.
- Feature: Saved clipboard items stay permanently, while separate pinned items also remain at the top of All.
- Feature: Clipboard management adds names, tags, text editing, multi-selection, image saving, previous-app pasting and saved-item export/import.
- Feature: Clipboard categories and optional OCR extend EmbeddingGemma 2 image searching to image, saved and pinned collections, including text inside screenshots.
- Feature: Unified shortcut settings add reset defaults, conflict reassignment, Windows-key bindings and direct actions for search modes, clipboard controls and AI screen-area capture.
- Feature: AI screen-area capture attaches your selection after capture, and AI chat accepts pasted images with clickable thumbnails in conversation turns.
- Feature: Search modes can be reordered, and Ctrl+Tab cycles file types or clipboard categories.
- Feature: Smarter query parsing recognizes filename extensions and media intent in searches such as andrew pdf, dog photos and dog videos.
- Documentation: The README introduces Windows search, Clipboard, Web and AI Chat with examples and updated setup instructions, while retaining the Models and tools reference.

## Fixes since the last full release (0.3.40)

- Fix: Image-intent clipboard searches such as dog images prioritize matching pictures over literal text matches.
- Fix: Elevated file opening uses desktop Explorer so mapped network drives remain accessible in the user session.
- Fix: Double-Ctrl accepts mapped-drive and UNC folder scopes from Explorer without rejecting them because of elevated-process drive mappings.
- Fix: Search hides confirmed missing local files without deleting index records and explains when an activated file has moved or been deleted.
- Fix: File icons fall back to extension associations when necessary and preserve transparent pixels.
- Fix: Clipboard image previews preserve their original aspect ratio.
- Fix: Quoted Markdown inside bullet lists uses the available response width instead of being squeezed against the right edge.
- Fix: Main and popup windows remember separate monitor positions and avoid geometry changes while being dragged.
- Fix: GPU utilization reports the busiest physical engine instead of adding independent engine percentages.
- Fix: File-monitor queue-count logs are throttled while live status remains current.
- Fix: Common-cache exclusions additionally cover packaged LocalCache, TempState and browser/graphics caches while preserving other Quick AppData paths.
- Fix: Newly excluded records are removed in bounded batches without requesting a full filesystem scan.
- Fix: Installation checks VectorDash specifically instead of asking to close unrelated diagnostic applications such as Process Explorer.
- Fix: Bounded preview caches and releasing hidden-window UI caches reduce retained memory.
