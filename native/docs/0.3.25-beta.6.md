# VectorDash 0.3.25 Beta 6

- Expanded all 13 interface catalogs from 99 core messages to 706 messages, covering settings/help, hardware, sources, scheduling, Models and AI, confirmation dialogs, About/update controls, tray menus and app-owned status summaries. Technical identifiers and user/third-party content stay unchanged. Translations remain beta and need native-speaker review.
- Fixed tray Exit delivery and processing: actions are enqueued before their repaint notification, Exit is retained when the queue is full, and quit processing runs before close-to-tray interception. Native tray menus also accept right-button selection.
- Integrated the experimental camera RAW feature. Enable Sources → Index camera RAW photos, save and update a Full source. RAW remains off by default. Embedded previews are preferred; optional reduced-resolution development handles files without usable previews. Originals stay untouched and Quick indexing remains filename-only.
- Bundles the isolated LibRaw decoder, with separate input size, memory, time and output-size limits. RAW files use the existing image search, thumbnails and Quick Look paths.

Validation: 189 automated tests passed (10 opt-in tests not run). All 13 languages rendered, seven Spanish settings pages checked, and ten consecutive hidden-window Exit attempts succeeded. Ten freshly downloaded CC0 samples covering ARW, CR2, CR3, DNG, RAF, NEF, ORF, RW2, PEF and SRW decoded and indexed using a real EmbeddingGemma server in an isolated index: 10 files / 10 vectors in 4.9 seconds using the optimized packaged executable with a warm server. Every file was found by name in Images, semantic search returned RAW results, and an unchanged rescan took 0.14 seconds with zero embedding requests. Nine samples used embedded previews; the Raspberry Pi DNG used development fallback. All original checksums stayed unchanged. These timings are a small test set, not a general throughput or relevance benchmark. Additional tests exercised development fallback, corrupt-file handling, Unicode paths, orientation and disabled/Quick behavior.

Includes all Beta 5 reliability fixes and localization. Windows 10 support remains beta. No index rebuild is required for the UI fixes; after enabling RAW, Update index adds visual content to existing Full-source RAW entries.
