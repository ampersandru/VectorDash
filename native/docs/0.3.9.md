# VectorDash 0.3.9
- Uses the original VectorDash installer identity and installation folder, so setup upgrades the Python installation instead of creating a parallel app.
- Windows Installed apps, shortcuts and executable product/file descriptions use VectorDash.
- A successful installation removes a separately registered Rust preview, preserves its data, and carries forward its startup entry.
- Startup uses the VectorDash registry entry and removes the obsolete preview entry when changed.
- Removes the old bundled Python runtime during upgrade; settings, downloaded models and indexes are retained outside the installation.
- Older Python indexes remain available for copy import through Sources. Existing native data stays in its current location.

The installer remains unsigned. Close VectorDash before installing.

Validation: an isolated real Inno Setup upgrade reused the mock Python installation directory, produced one VectorDash registration, removed the separate preview and old Python runtime, and preserved both in-directory and external data fixtures. Executable ProductName/FileDescription are VectorDash and ProductVersion is 0.3.9.
